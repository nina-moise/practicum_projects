# SollmaFin - мобильное приложение для онлайн-торговли финансовыми активами 

[html](https://github.com/nina-moise/practicum_projects/blob/main/SollmaFin_ab_test/SollmaFin_ab_test.html) [ipynb](https://github.com/nina-moise/practicum_projects/blob/main/SollmaFin_ab_test/SollmaFin_ab_test.ipynb)

Проект посвящен полному анализу результатов A/B-тестирования в финтех-сервисе. Основной акцент сделан на изучении **стабилизации метрик** во времени и использовании непараметрических методов (**Bootstrap**) для оценки значимости различий.

## Цели проекта
1. **Анализ исторических данных:** привлечение новых пользователей, классическая и пошаговая воронка, ARPU.
2. **Анализ корректности проведения А/В эксперимента:** оценить аудиторию эксперимента, как ведут себя накопленные метрики в процессе теста, 
стабильность p-value во время эксперимента.
3. **Статистическая проверка:** Применить метод **Bootstrap** для оценки доверительных интервалов и сравнения групп в условиях сложного распределения данных.

## Технологический стек
* **Python** (Pandas, NumPy, Scipy)
* **Статистика:** Тест Уэлча (Welch’s t-test) для сравнения средних при неравенстве дисперсий, Метод Bootstrap (ресемплинг), квантильный анализ (Percentile method), кумулятивные метрики (Expanding/Rolling mean).
* **Визуализация:** Seaborn, Matplotlib (построение графиков стабилизации и распределений средних).

## Ключевые этапы и навыки

### 1. Применение метода Bootstrap
В условиях, когда данные имеют «тяжелые хвосты» или нетипичное распределение, был применен Bootstrap:
* Сгенерировано более 1000 подвыборок для каждой группы.
* Рассчитано распределение средних значений (Sampling Distribution), которое согласно **ЦПТ** стремится к нормальному.
* Построен 95%-й **доверительный интервал** (Confidence Interval).

### 3. Визуальный анализ (EDA)
* Использована **ядерная оценка плотности (KDE)** для визуализации распределений после бутстрапа.
* Построены графики кумулятивных метрик, наглядно показывающие разрыв (или его отсутствие) между тестовой и контрольной группами в динамике.

## Результаты и инсайты
* Выявлена точка стабилизации метрики, что позволило подтвердить достаточность набранной выборки для корректных выводов.
* С помощью Bootstrap-анализа определено перекрытие доверительных интервалов, что дало ответ на вопрос о статистической значимости внедряемых изменений.

* **Итог:** Сформулированы рекомендации для бизнеса на основе данных, а не случайных колебаний в начале теста.
