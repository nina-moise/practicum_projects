# Конференции TED

## Цель проекта
Заказчик хочет провести конференцию в духе классических конференций TED, учитывая  опыт уже проведённых конференций и просит разработать дашборд с ответами на следующие вопросы:

+ Какие темы популярны? Как зрители реагируют на них?
+ Какое среднее количество выступающих на одной конференции?
+ Какая средняя длина выступления? Как правильно организовать время проведения конференции?
+ Кто из выступающих интересен зрителям?

[Описание данных](https://github.com/nina-moise/practicum_projects/blob/main/TED_conferences/Data_Description.pdf)

## Навыки и инструменты
+ **SQL**
+ **DataLens**
  
## Итог проекта
[Ссылка на дашборд](https://datalens.yandex/hc7c43jsmilm3) 
+ Дашборд построен по принципу Longread/Landing page - пользователь идет от выбора в селекторах вверху дашборда к результатам выбора в деталях внизу. 
+ Я использовала скролл-ориентированный дизайн (Storytelling).
+ Акцент сделан на UI/UX, чтобы интерфейс был интуитивно понятен конечному пользователю без инструкций, в единой цветовой гамме.
+ Дашборд реализован как набор Wizard- и [QL-чартов](https://github.com/nina-moise/practicum_projects/blob/main/TED_conferences/TED_sql_query.sql).
