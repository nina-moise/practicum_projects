# Cервис доставки еды «Всё.из.кафе"

## Цель проекта
- Подготовка данных, разработка дашборда и визуализация ключевых метрик для сервиса доставки еды «Всё.из.кафе» в г.Саранске за период с 1 мая по 30 июня 2021 года.
- Визуализация и анализ и следующих метрик: **DAU, CR, AOV, LTV, RR**. 
- Составление аналитического отчета на основе этого дашборда.
  
## Навыки и инструменты
+ **SQL**
+ **DataLens**
