## Сервис такси «Карету мне»
Проверка продуктовой гипотезы с помощью А/В/С эксперимента

[html](https://github.com/nina-moise/practicum_projects/blob/main/Taxi%20service/taxi_service_ab%D1%81.html) [ipynb](https://github.com/nina-moise/practicum_projects/blob/main/Taxi%20service/taxi_service_ab%D1%81.ipynb)

Проект посвящен полному циклу работы с продуктовым экспериментом: от проектирования дизайна и расчета чувствительности до статистического анализа результатов. Основной вызов проекта — работа с метрикой отношения (**Order-to-Ride**) в условиях высокой дисперсии данных.

## Цели проекта
1. **Дизайн эксперимента:** Рассчитать размер выборки для заданного занчения минимально детектируемого эффекта (MDE не выше 4%).
2. **Проверка качества:** проверить корректность распределения трафика и оценить данные на предпериоде.
3. **Анализ результатов:** Сравнить 3 экспериментальные группы и сделать бизнес-вывод об эффективности изменений.

## Технологический стек
* **Python** (Pandas, Numpy, Scipy)
* **Статистика:** t-критерий Стьюдента, **Линеаризация (Linearization)** для Ratio-метрик, расчет мощности и MDE.
* **Визуализация:** Seaborn, Matplotlib (анализ распределений и выбросов).

## Ключевые этапы
### 1. Дизайн и расчет чувствительности (MDE)
Для определения порогов чувствительности теста был использован метод линеаризации.
* **Почему линеаризация?** Обычный t-тест на средних по пользователям смещает оценку Ratio-метрики. Линеаризация позволила учесть «вес» (количество заказов) каждого пользователя.
* **Результат:** При заданных параметрах ($\alpha=0.05, \beta=0.2$) и разделении трафика на **3 группы**, и заданном относительном MDE не выше 4%, объем трафика составил 50% (MDE =  3.16%).

### 2. Исследовательский анализ (EDA)
* Визуализировано распределение линеаризованной метрики с помощью **KDE (ядерной оценки плотности)**. Подтверждена центровка относительно нуля и форма распределения, близкая к нормальной (согласно ЦПТ).
* Выявлены и проанализированы выбросы в количестве заказов на пользователя, что подтвердило необходимость использования устойчивых к шуму методов.

### 3. Анализ результатов A/B/C-теста
В эксперименте участвовали три группы (одна контрольная и две тестовых).
* **Методология:** Сравнение средних линеаризованной метрики между группами.
* **Множественная проверка:** Учтены риски накопления ошибки I рода при сравнении нескольких групп.
* **Итог:** На основе полученных p-value и сравнения с MDE были сформулированы рекомендации по внедрению (или отклонению) тестируемых изменений.

## Главные выводы
* Использование линеаризации позволило перевести сложную метрику отношения в линейную форму, сохранив при этом вклад каждого пользователя в общий результат.
* Расчет MDE показал, что тест обладает достаточной мощностью для фиксации продуктовых изменений выше 3.16%, что является адекватным порогом для высокочастотного сервиса такси.
